# EMBERHOLD

Defend the Ember Lantern through twelve moonlit waves. Build four kinds of sentries on the moss plots, then survive the Hollow King.

Run `node serve.ts` and open `http://127.0.0.1:8080`. Click Begin, select a plot, choose a tower along the lower edge, then press Space to summon the next wave. Keys 1–4 choose a tower, U upgrades, X sells, P pauses, F changes speed, M mutes, and R restarts after the ending. You can also place, upgrade, sell, and start waves with the on-screen controls.
